## 💡 Что понял
Nat - это технология которая из локальной сети посылает ip адрес на роутер, в свою очередь роутер через свой публичный ip адрес отправляет запрос в сеть и получает ответ, так же здесь в строке есть название портов, чтобы понимать за чем идет запрос(веб сервер и т.д)
Два виртуальных адаптера нужны для того чтобы на одном из них был nat выше описал, засчет второго адаптера я могу управлять виртуальной машиной со своего компьютера (host only adapte)
